# Curated tables and the committed vocabulary subset

Two kinds of table live here.

**Curated** (hand-maintained, the mapping decisions this prototype makes):

| File | Columns | Notes |
| --- | --- | --- |
| `onset_bands.tsv` | band_text (normalised), hpo_id, note | the note column records each boundary assumption |
| `lay_terms.tsv` | text (normalised), hpo_id | lay phrases seen in free-text answers |
| `drug_lexicon.tsv` | text (normalised), rxcui, label | RxNorm has no licence-free bulk file, so this is the only drug source; checked against RxNav 2026-11-11 |
| `survey_lookups/<registry>_<instrument>_<version>.tsv` | question_id, hpo_id | per survey version, for registries whose checklists carry no codes |
| `diseases.tsv` | mondo_id, label, orphanet, omim, gene_symbol, hgnc_id, hpo_pool | the synthetic generator's disease catalogue; also the crosswalk's fallback when no release tables are present |

**Derived** (a slice of the releases, regenerated by `make assets-subset`, do not edit):

| File | Columns | Source |
| --- | --- | --- |
| `hp_terms.tsv` | id, label, obsolete, replaced_by, kind (feature or onset) | hp.json, HPO release in `versions.yml` |
| `hp_synonyms.tsv` | synonym, hpo_id, scope | hp.json |
| `mondo_xrefs.tsv` | xref, mondo_id, mondo_label, predicate | Mondo SSSOM (OBO purl) |
| `mondo_labels.tsv` | mondo_id, label | Mondo SSSOM |
| `genes.tsv` | symbol, hgnc_id, name, kind (symbol, alias, prev) | HGNC complete set |
| `versions.yml` | release identifiers; `subset: true` | written into each phenopacket's `metaData.resources` |

The subset keeps only identifiers referenced by the curated tables, their live replacements,
and the whole HPO Onset subtree. Full tables for a real run come from `make vocab` into
`vocab/tables/` (not committed). `NO_HP_JSON` is a placeholder the pipeline stages when
`--hp_json` is not given.
